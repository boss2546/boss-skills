# 🏦 P.D.B Vault — เริ่มที่นี่

นี่คือ **Obsidian vault ของ Personal Data Bank** — ที่ที่ผลลัพธ์รายวันจะมาลง

## จะมีอะไรโผล่ที่นี่
เมื่อรัน `node tools/digest.js <YYYY-MM-DD>` จะได้ 3 อย่างต่อวัน:

- **`<วัน>.md`** — โน้ตสรุปรายวัน (สรุป + หัวข้อ + `[[คน]]`/`[[โปรเจกต์]]` + สิ่งที่ต้องทำ)
- **`<วัน>/_full.md`** — ข้อความสะอาดฉบับเต็ม (lossless · ของจริงอยู่ที่นี่)
- **`<วัน>/_removed.log`** — บันทึกว่าล้างอะไรออกไป (ตรวจย้อนได้)

## หมายเหตุ
- ยังว่างอยู่เพราะ MVP ยังไม่ได้ implement (อยู่ขั้นเขียนแผน)
- โฟลเดอร์นี้ **gitignored** — ข้อมูลส่วนตัวอยู่ในเครื่อง ไม่ขึ้น git/cloud
- ลองใช้ Graph view ของ Obsidian เพื่อเห็นความสัมพันธ์ระหว่างคน/โปรเจกต์เมื่อมีโน้ตแล้ว
