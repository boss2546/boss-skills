AI เขียน .md ยังไง?

คำตอบสั้น: AI ไม่ได้เขียน .md ตรงๆ — AI เขียนแค่ "เนื้อ" เป็น JSON แล้ว โค้ด template เป็นคนเขียน "โครง" markdown

🤖 AI ทำ
คิด "เนื้อหา" → คืนเป็น JSON (สรุป/หัวข้อ/คน/ตัดสินใจ)
⚙️ โค้ดทำ
จัด "โครงสร้าง" markdown ตาม template ตายตัว (หัวข้อ/ลิงก์/checkbox)
① OUTPUT จาก AI ตอบเป็น JSON เท่านั้น (response_format: json_object)
{
  "summary": "เจ้าหน้าที่กงสุลและผู้แทนจาก T-Hub จัดกิจกรรม...",
  "topics": ["ความร่วมมือไทย-อินเดีย", "Soft Power", ...],
  "people": ["Tushar Sharma", "สมสุข"],
  "projects": ["T-Hub", "India Dekho", ...],
  "todos": ["หาแนวทางร่วมมือ T-Hub", ...],
  "decisions": ["มุ่งเน้นร่วมมือกับ T-Hub...", ...]
}
// → parseDigest() แกะ JSON · groundEntities() ทิ้งคน/โปรเจกต์ที่ไม่มีในต้นฉบับ
↓renderNote(date, digest) — ฟังก์ชันเพียว ไม่มี AI
② TEMPLATE ในโค้ด เท JSON ลงโครงตายตัว (write-obsidian.js)

## คน / โปรเจกต์

รูปแบบไม่มีวันเพี้ยน

หัวข้อ/ลิงก์/checkbox มาจาก template — AI พลาดได้แค่ "เนื้อหา" ไม่ใช่ format

เทสได้ ไม่ต้องยิง AI

renderNote เป็นฟังก์ชันเพียว → มี unit test คุมโครงโน้ตโดยตรง

ได้ JSON ฟรีไปด้วย

JSON ก้อนเดียวกันถูกเซฟเป็น .json = เมล็ด Vault/MCP ในอนาคต

ข้อควรรู้: เพราะ AI คุม "เนื้อ" ความผิดที่เป็นไปได้คือเนื้อหาคลาดเคลื่อน (เช่น เคยเดาเดือน "สิงหาคม" ที่ไม่มีในต้นฉบับ) — แก้ด้วยการรัดกุม prompt + ground ฟิลด์ todos/decisions เพิ่ม ไม่ใช่ที่ตัว template
